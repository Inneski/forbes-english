must vs have to — Quick Ref

must

〜しなければならない (強い義務・内側から)
Speaker's own authority / strong personal feeling
Rules you impose yourself
No past tense form — use had to
// You must read the docs carefully.
// This code must not run in production.

have to

〜しなければならない (外側からの義務・ルール)
External rules, laws, workplace policy
Has past: had to, future: will have to
Has all persons: he/she has to
// You have to push to a feature branch.
// She had to rewrite the whole function.

mustn't

〜してはいけない (禁止)
Prohibition — it is forbidden
Strong warning, danger, rule
// You mustn't push to main directly.
// ⚠️ You must NOT hardcode API keys.

don't have to

〜しなくてもいい (不必要)
No obligation — it's optional
Opposite of mustn't! No prohibition
// You don't have to use TypeScript.
// She didn't have to attend the standup.
