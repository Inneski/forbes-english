# Sherpa Tensing — Midjourney prompts, one per image

Copy each block straight into Midjourney. The file name above each block is the name to save the picture under, so the builder picks it up with no code change. Background: `docs/ARTWORK-sherpa-tensing.md`.

Upscale before saving: base renders are under the 1400px minimum. Keep one half of each hero quiet: the cover card sits on whichever half is calmer, and the builder measures which. The colour no longer has to be in the picture; the deck takes it from the route map (2026-09-24).

Textures carry `--tile` so they repeat without a seam. Drop it if a result looks too patterned.
