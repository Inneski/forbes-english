# Dead by Teatime: artwork brief for ChatGPT

Generated by `py lesson-template/build/build_dead_by_teatime.py --brief`; edit PLATES in the builder, not this file.

## How to use it

1. Start one ChatGPT conversation and paste **The style** and **The people** below as the first message, with: "Keep this style and these people for every picture I ask for in this chat."
2. Then ask for each picture by pasting its line, one picture per message.
3. Save each picture as the file name shown (`hero.png`, `brief.png` …) in `incoming/dead-by-teatime/`. The folder already exists on this machine.
4. Run `/publish`, or tell Claude the pictures are in. The deck builds itself from them.

## The style

Flat graphic poster illustration in the style of a mid-century screen print: bold silhouettes, negative-space tricks where one shape hides another, a limited palette of four or five flat colours (dusk blue, coral red, cream, near-black, one touch of bowling-alley neon pink), fine paper grain, no gradients beyond a soft sky. Wry and funny, never gory: no blood, no wounds, the undead only ever as slow dark silhouettes. 16:9 landscape. Put the subject in the RIGHT half of the picture and keep the LEFT half calm, plain background (sky, wall, street), because slide text sits there. No words, letters, numbers, logos or signatures anywhere in the image.

The town is LOWFIELD, a small English commuter town: terraced houses, a high street, a 1980s bowling alley called Lowfield Lanes.
