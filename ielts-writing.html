Academic Module · C1 · Writing

IELTS Academic Writing

Twelve lessons, in order. Start with the Report. Task 1 comes first here because it comes first on the paper — but Task 2 carries twice the marks, so that is where the hours should go. The numbering is teaching order, which is why the model answers (Part 4) sit before the timed practice (Part 3).

Every lesson is click-through, scored where scoring teaches something, and ends with writing you actually produce rather than recognise.

This is the Academic module. Task 2 is the same on General Training, but GT Task 1 is a letter, not a report — so the Task 1 lessons below will not match a GT paper.
