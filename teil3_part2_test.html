Adverbs of manner

Adjektiv + -ly → quick → quickly, careful → carefully
-y → -ily  ·  happy → happily
-le → -ly  ·  terrible → terribly
Ausnahmen: good → well  ·  fast → fast
Das Adverb beschreibt das Verb — das Adjektiv beschreibt das Nomen.

will / won't

subject + will / 'll + Grundform  ·  I'll go, she'll win
subject + won't + Grundform  ·  I won't know, it won't be fun
Gleiche Form für alle Personen — kein -s. Nach will/'ll immer die Grundform.

So … I  /  Neither … I

Positiver Satz → So + Hilfsverb + I
Negativer Satz → Neither + Hilfsverb + I
I like rap. → So do I.  ·  I can't swim. → Neither can I.
Das Hilfsverb spiegelt die Zeitform des Vorgängers — do/did/have/can.
