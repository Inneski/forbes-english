# Drop files here, then run `/publish`

Midjourney images, a lesson HTML, an RPG export, a note saying what you want.
Open a **local** session on this clone (Claude Code, or the desktop app on
this folder) and type `/publish`. It prepares the artwork, builds the lesson,
adds the catalogue row, runs SEO, redirects old pages, pushes, and clears
this folder.

Nothing in here is committed. A cloud session cannot see this folder.
