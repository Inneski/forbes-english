When to use it

One letter from its neighbour and nothing like it. This is not a past habit — it is a present state, a description of how you are right now, and it takes a noun or an -ing form, never an infinitive.

Something has stopped being strange

The state of finding a thing normal, having once found it odd.

"I'm used to the noise now."

It takes a noun or an -ing

Never an infinitive. This is the error that gives it away.

"I'm used to getting up early."

It moves through the tenses

It is an ordinary adjective phrase, so be does the usual work.

"I was used to it by then." · "You'll be used to it soon."

Get used to = the process

Becoming familiar, rather than already being familiar.

"I'm getting used to the shifts."

The negative is common and useful

Most often you are explaining why something is hard.

"She's not used to the cold."

It says nothing about the past

Unlike its neighbour, it makes no claim that anything has stopped.

"I'm used to living alone." — and I still do
Building it

How it's built

Affirmative

subject + am / is / are + used to + noun or -ing

"He's used to the early shifts."

Negative

subject + am / is / are + not + used to + …

"They're not used to the heat."

Questions

Am / Is / Are + subject + used to + …?

"Are you used to it yet?"

Becoming

get / am getting / got + used to + …

"I got used to it quickly."

The three forms, side by side

This is the chart worth learning by heart. Three phrases, one letter apart, three different jobs.

FormMeansExample
used to + infinitivea past habit that has stopped"I used to live here." — I don't now
be used to + -inga present state: it is normal to me"I'm used to living here." — I still do
get used to + -ingthe process of becoming familiar"I'm getting used to living here."
would + infinitivea repeated past action only"We would walk there every Sunday."

What can follow it

After used to in this phrase comes a thing, never an action in its plain form. If you can put it there, you can put an -ing there.

Follows withExampleRight?
a noun"I'm used to the noise."Yes
a pronoun"I'm used to it."Yes
an -ing form"I'm used to working nights."Yes
an infinitive"I'm used to work nights."No — this is the classic error

Three mistakes worth naming

Almost every error with this phrase is one of these three.

Not thisThisWhy
I'm used to get up early.I'm used to getting up early.After this to comes a thing, not an action. The -ing makes it a thing.
I used to the noise.I'm used to the noise.The phrase needs be. Without it you have accidentally written the other form.
I'm used to live here.I used to live here. / I'm used to living here.Both are English and they mean opposite things. Decide which you mean.
The fork in the path

Which of the two do you want?

They differ by one word and they point in opposite directions. Used to looks back and says something ended. Be used to looks at now and says something is normal.

Questionbe used to + -ingused to + infinitive
When is it true?Now.
"I'm used to the cold."		It was true, and stopped.
"I used to hate the cold."
What follows?A noun or an -ing.An infinitive.
Can it change tense?Yes: was used to, will be used to.No. Past only.
Is be there?Always.Never.

The pair that decides it: "I used to live alone" — I have a flatmate now. "I'm used to living alone" — I still do, and it suits me. One word apart, and the second one is the only one that tells you where I live today.
